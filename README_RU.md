# AIcreator (ИИ-ассистент для редактора Geometry Dash)

Мод для **Geode** (Geometry Dash 2.208+), добавляющий умного ИИ-ассистента прямо в редактор уровней. Нейросеть отвечает на вопросы по созданию уровней и умеет сама расставлять объекты на сетке по текстовому запросу.

## Возможности
* **Встроенное окно чата в редакторе** — открывается по кнопке с иконкой мозга в верхней панели, свободно перетаскивается за шапку и растягивается за правый нижний угол.
* **Автопостройка объектов** — попросите ИИ построить препятствие, полосу с шипами или поставить порталы, и мод сам заспавнит объекты рядом с камерой.
* **Бесплатная работа через Cloudflare Workers AI** — до **10 000 нейронов в день** бесплатно (хватает примерно на 150–300 запросов в сутки без привязки банковской карты).
* **Кнопка экстренной остановки (`STOP`)** — позволяет мгновенно прервать зависший запрос.

## Установка мода
1. Скачайте актуальный файл `.geode` из раздела [**Releases**](../../releases).
2. Откройте **Geometry Dash** с установленным **Geode**.
3. Перейдите в меню модов Geode -> **Install from File** (или закиньте файл в папку `geode/mods`) и перезапустите игру.

---

## Настройка (получение бесплатных ключей Cloudflare)

Чтобы ИИ начал отвечать и строить, нужно один раз указать свой **Account ID** и **API Token** от Cloudflare:

1. Зарегистрируйтесь или войдите на сайте [://cloudflare.com](https://://cloudflare.com/).
2. В левом меню откройте **AI** -> **Workers AI** и нажмите **Use REST API**.
3. Скопируйте свой **Account ID** (32 символа) и создайте **API Token** (нажмите *Create a Workers AI API Token*).
4. Вставьте оба значения одним из двух способов:
   * **Способ 1 (через игру):** откройте настройки мода **AIcreator** в меню Geode и впишите `cf-account-id` и `api-key`.
   * **Способ 2 (через файл):** откройте редактор уровней один раз — мод автоматически создаст файл `ai_config.txt` в папке конфигов мода (`geode/config/custom.ai_editor_assistant/ai_config.txt`). Впишите туда свои данные:
     ```env
     CF_ID=ваш_32_символьный_account_id
     CF_KEY=ваш_api_token
     ```

## Сборка из исходников
